# Changelog

## 0.3.0 - 2026-09-29

- Added live city suggestions while typing, including region and country details from Open-Meteo geocoding.
- Added a responsive suggestion panel so users can choose the correct city before loading its forecast.
- Simplified the header by removing the redundant live weather label.
- Organized the source tree into app, map, and weather feature folders.
- Improved GitHub Pages deployment documentation and release metadata.

## 0.2.0 - 2026-09-28

- Added live air quality readings for US AQI, PM2.5, and PM10 through Open-Meteo Air Quality.
- Added regional pollen readings with clear availability states for grass, birch, and ragweed.
- Added forecast-based gardening guidance for watering, planting, heat, and rain planning.
- Added an OpenStreetMap location view with a current RainViewer radar overlay.
- Added Leaflet map controls, responsive feature panels, and mobile-friendly map layouts.

## 0.1.0 - 2026-09-28

- Added live current weather and seven-day forecasts through Open-Meteo.
- Added city search, recent city shortcuts, dark mode, and automatic ten-minute refreshes.
- Added responsive styling and GitHub Pages deployment workflow.
