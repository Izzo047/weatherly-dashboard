# Contributing to Weatherly

Thanks for helping improve Weatherly.

## Local setup

1. Install Node.js 20 or newer.
2. Run `npm install`.
3. Run `npm run dev`.
4. Run `npm run build` before opening a pull request.

## Pull requests

Keep changes focused, describe the user-facing result, and include screenshots for visual changes. Please do not commit `node_modules`, `dist`, or local environment files.

Weather data comes from the public Open-Meteo API. Keep API requests browser-safe and avoid adding private credentials to the repository.
